# Vendas Analytics Project

Projeto fictício de análise de vendas com foco em:
- Modelagem de banco de dados (DER)
- Análise de métricas de vendas
- Desenvolvimento de aplicações web

## Objetivo
Criar uma base estruturada para análise estratégica de vendas.

## Tecnologias previstas
- Python
- SQL
- Banco de dados Relacional
- (futuramente) Flash ou outro framework web
